# 🌱 Sprout 2.0 — UI/UX Design Challenge

A beginner-friendly investing experience designed for Sprout, an Indian mobile investing app that helps first-time investors take their first steps toward investing.

## 📌 Project Overview

Sprout 2.0 is a UI/UX design challenge focused on improving the experience of first-time investors. The design aims to make investing feel less intimidating by providing clear information, simplified onboarding, and transparent verification progress.

The project connects the website homepage with the app onboarding journey to create a consistent and accessible user experience.

## 🎯 Objectives

- Build trust with first-time investors through a clean, approachable interface.
- Simplify the user journey from discovering Sprout to exploring investments.
- Help users prepare for KYC verification in advance.
- Provide clear verification progress and waiting states.
- Create a responsive, accessible, and user-friendly experience.

## 🎨 Design Approach

The design uses a minimal, modern fintech aesthetic with sage green, warm cream, and forest green to create a calm and trustworthy visual identity.

A simple sprout mascot represents growth, learning, and confidence. It adds personality without compromising the premium look of the interface.

The experience prioritizes clear typography, intuitive navigation, consistent components, and a prominent primary call to action.

## 🖥️ Deliverables

- Desktop homepage
- Mobile homepage
- Five mobile onboarding screens:
  1. Welcome
  2. Learn about investing
  3. KYC preparation
  4. Verification and waiting state
  5. First-investment discovery
- Sprout mascot concept
- Design system and reusable components
- Clickable Figma prototype

## 🔄 User Journey

**Discover Sprout → Get Started → Learn → Prepare KYC Documents → Verify Details → Explore Investments**

The homepage introduces the product and encourages users to begin. The onboarding screens guide users through each stage, explain document preparation, and communicate verification status clearly.

## ♿ Accessibility and Usability

- Readable typography and clear visual hierarchy.
- Accessible color contrast following WCAG AA requirements.
- Touch targets of at least 44 × 44 pixels.
- Responsive layouts designed for mobile devices.
- Clear progress indicators and verification feedback.
- Visible investment risk information.
- Flexible layouts that can support future Hindi and regional-language translations.

## ⚡ Key UX Decisions

- Used a minimal visual style to reduce distractions.
- Introduced KYC preparation before verification to reduce uncertainty.
- Designed explicit waiting states to prevent users from thinking the app has frozen.
- Kept the mascot subtle to balance friendliness with a premium aesthetic.
- Avoided misleading financial promises and unnecessary promotional elements.
